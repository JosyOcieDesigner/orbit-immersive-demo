# Cek Artis — Immersive Portfolio

Konten, logo, 42 proyek, showreel, creative journey, logo klien, dan kontak disesuaikan dari repository milik pengguna: https://github.com/JosyOcieDesigner/creative-event-portfolio

Palet: hitam #090909, lime #d7ff2f / #d7ff00, biru #3434ff. Hero menambahkan kubus Three.js interaktif yang bisa diputar dengan drag. Tombol Pause motion menjeda animasi dan video lokal.

Website: https://josyociedesigner.github.io/orbit-immersive-demo/

Untuk preview lokal: `python3 -m http.server 4173`. Deploy GitHub Pages dari main, root. Semua jalur aset lokal relatif, kompatibel dengan subfolder repository. Video portofolio dan showreel menggunakan YouTube dari sumber referensi dan membutuhkan koneksi internet.

Three.js menggunakan lisensi MIT di vendor/THREE-LICENSE.txt. Repository sumber tetap tidak diubah.
